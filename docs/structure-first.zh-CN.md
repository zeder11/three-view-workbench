# 先读结构，再生成模型（实验）

在「AI 建模 → 直接生成 → 接口设置」勾选「实验：先读结构，再生成模型」，再主动点「生成模型」。默认关闭；普通直接生成和粘贴 JSON 保持原来的方式。

开启后，新生成按两个阶段运行：

1. 读取原题，记录部件、材料与空腔、孔槽轴向、深度分区、相互关系、尺寸来源和不确定项。
2. 再次提供相同原题及这份结构假设，按原有模型格式生成几何，并沿用本机校验与独立预览。

结构记录只是 AI 的假设，不是用户给定条件或正确答案。第二阶段须重新对照原题，可以纠正第一阶段的误读；程序尚未验证这些描述是否符合图片。

每次新生成最多发送两次请求，每阶段各一次，不自动重试、不静默切换为直接生成。任一阶段出错或截断便停止，保留工作台和原候选；可主动重试。两阶段沿用当前服务商、模型、思考设置和**每次请求**的输出额度，因此总用量与等待时间可能增加，题图也会发送两次到所选服务商。使用同一取消按钮可以停止整个流程。

「按说明修正」、答复更新、结构重建及原图复核仍按原流程执行，不自动重读结构，原图复核的修改范围保护保留。外部 AI 的复制说明与粘贴入口不要求额外字段。

成功后可在「详细信息」中展开「初次读图记录 · AI假设」，接口诊断会区分读取结构和生成模型。读图计划只用于本次候选，不写入导出的几何模型，也不会变成用户确认过的事实。

两阶段是否提高正确率仍需实测，不应凭结构说明更详细就认为几何正确。实验入口保持默认关闭，适合对同一题比较后自行选择。
