# 题图辅助：像素观测

清晰的第一角三视图或上主下俯两视图，可在请求前由本机提取整件的共同外包比例，以及部分较长水平、竖直墨迹的范围与端点。它提供读图辅助，不判断完整立体、材料关系、通盲或整题正确性。

## 使用

- 内置生成：仍点「生成模型」。可提取的观测随原图进入同一次请求，不增加一次AI调用。
- 外部AI：先在本软件选择原题，再点「复制给AI的说明」或下载说明。说明包含当前补充文字及可提取的观测；原题图片仍需另附给外部AI，说明不含图片字节或接口Key。
- 粘贴JSON：不借用上传区其他图片。给当前候选明确「关联原题」后，使用同一套本机观测；候选与题图的外包比例有较大偏差时显示提示，模型不自动改动。

观测按本软件第一角布局解释，各图共用同一比例；每个轴取对应视图中最大的观测跨度，再把整件最大外包项归一为100。允许的小幅像素差异保留，不把线端点强行截短；明显的比例冲突会放弃观测。V使用X/Z，W使用Y/Z，H使用X/Y；这是相对坐标，不是毫米或尺寸标注。已标尺寸优先。墨迹的连续或规则断续样式不等于已经可靠识别了实线、隐藏线、中心线。

把一条横线解释成孔底前，仍需用原图核对它的端点、跨度是否对应两侧孔壁；较长的台阶线不能单独证明孔被封底。未列出的圆弧、短线及未提供的视图，不代表没有结构。

## 范围与回退

仅支持能可靠分区、共同尺度一致的较清晰正投影线图。轴测、剖视、第三角说明、倾斜照片、密集标注、裁断或未能可靠分离的辅助线，保留原图和原生成流程，不把未知信息当成约束。处理在本机Worker执行，约2.5秒上限；不可用不会自动重发AI请求。取消与换图后的旧回调不能改写新候选。

观测仅在页面内存中缓存，不写入模型JSON或自动保存记录；本机比例提示不增加应用确认、不自动调整尺寸。它不能替代原题尺寸、人工核对或证明模型唯一，也没有保证DS、GPT或其他AI都提高正确率。
