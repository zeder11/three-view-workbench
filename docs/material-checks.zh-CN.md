# 本机材料检查与受限修复

AI结果「详细信息 → 本机一致性检查」沿用原有入口，不增加必填项或逐项确认。

本版新增两种声明核对：

- **孔段仍有材料**：仅对声明为`through_hole`、关联圆柱减料步骤且最终轴向与X/Y/Z对齐的情况，追踪中心及四条半径内路径。若该特征只关联一个步骤，且给出同轴`spatial.range`，便按原单位实际孔段检查；否则只查刀具本身范围。可发现刀具偏短或后续补料堵孔。声明轴向与实际轴向不符也会提示。
- **声明接触却有间隙**：可选的`checks`记录具体两个加料步骤应直接接触。若它们的保守外包仍分离，便报告XYZ间隙。普通草绘、原生弧草绘和常见基本体均能提供保守外包；外包重叠不证明真正相接，后续切除也未被接触检查认证。

```json
{"checks":[{"kind":"contact","steps":[1,3],"source":"user","note":"底板与斜肋直接接触"}]}
```

步骤从1开始。最多16项，必须引用两个不同的加料步骤；`source`可用`drawing/user/estimate/unknown`，由AI填写的来源仍需核对。无效记录会跳过并给出警告，不修改几何，也不能视为检查通过。旧JSON不需要添加此字段。

有问题时点「只修检查涉及的步骤」，会主动请求AI：只允许修改被定位的问题步骤，保留原单位、顺序和其他步骤，不允许追加。没有定位到步骤的整件尺寸问题只作核对，不授予整件修改权限。权限不够或无法判断时应报告问题；可另用原有修正/复核入口指定范围。

孔深问题只改孔深及沿孔轴的起止位置，保留孔径、横向孔位和转角；孔轴方向冲突只改轴向选择，接触关联的加料不能改成减料。确需更换形状或孔位时使用原有修正入口。

这次修复沿用原来的有限重试，不自动连续修复，不启用额外读结构阶段，不自动应用。原声明（结构、孔段、接触、读数与假设）会保留复验，不能靠删声明或改文字消除警告。原候选可切回，越界修改仍被拦截；服务失败不替换原候选。

合法接触记录随AI来源信息保存和重新导入。旧版仍可读取几何，但不会执行新检查。

这些检查只核对**声明与本机几何是否矛盾**，不验证声明是否读对了题图。孔段路径不是整个截面的证明；斜孔、任意自由曲面和切除后的真实连接并未完整验证。检查没有发现问题，仍需看预览。

## 整件尺寸与局部尺寸

文字中的整件尺寸仍参与检查，但“总长60的凸台”“凸台总长60”等明确局部归属不会作为整件总长。“总长100，凸台宽20”中的整件总长仍会检查，不因后文出现局部结构而跳过。英文的直接局部归属（例如 overall length60 of the boss）同样排除。

这是有限的文字规则，不是通用语义理解。可选 readings 有明确的 scope:overall／feature 时，应按真实尺寸归属填写；检查没有发现冲突，不证明题图或尺寸已读对。
