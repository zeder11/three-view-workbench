# 复杂轮廓练习：哪段该画实线、虚线，或不画？

这 17 个例子是独立建的练习模型。用 [v0.5.3 工作台](../../app/three-view-workbench.html) 的「模型文件 → 导入模型文件」打开 JSON。立体显示选「透视轮廓」，再切到表中的标准视角，就能和左边的图纸对照。想看孔有没有被填实，可以用「剖开看看」。

| 模型 JSON | 建议视角 | 核对什么 |
| --- | --- | --- |
| [01 · 拼接支座的横向通孔](01-seam-through-bore.json) | 俯视 | 两块材料的接缝不应吞掉通孔的两条虚线。 |
| [02 · 开窗露出半段孔壁](02-open-window.json) | 俯视 | 中段露出画实线，两端被挡画虚线。 |
| [03 · 孔中间补料成两个盲孔](03-local-plug.json) | 俯视 | 两端孔线还在，中间填实的地方不延续虚线。 |
| [04 · 两段不同孔径的阶梯通孔](04-stepped-bore.json) | 主视、俯视 | 主视能看到内外圆；俯视两段各按实际孔径画虚线。 |
| [05 · 竖孔与横孔相贯](05-cross-drilled.json) | 俯视 | 竖孔孔口是实线，横孔虚线到相贯区域时应断开。 |
| [06 · 转向支座的跨缝通孔](06-turned-support.json) | 主视 | 把支座转向后，主视图仍应保留两条遮挡线。 |
| [07 · 圆弧吊耳与底座的共面孔](07-arched-eye.json) | 俯视 | 小孔的可见段画实线，被吊耳挡住的段画虚线，扩孔挖掉的那段不延续小孔线。 |
| [08 · 凸台盲孔与真实孔底](08-blind-floor.json) | 主视、俯视 | 俯视看孔口；主视的两条孔壁虚线应在孔底停止。 |
| [09 · 对向盲孔之间的薄隔层](09-opposed-blind-web.json) | 主视 | 两个孔底都画虚线；中间的薄隔层不应被画成通孔。 |
| [10 · 沉孔台阶与小通孔](10-counterbore-shoulder.json) | 主视、俯视 | 俯视能看到两个同心圆；主视能分清台阶和小孔的深度。 |
| [11 · 圆柱与球面相切的圆顶](11-smooth-dome.json) | 主视 | 光滑相接处没有横向接缝，外轮廓要连续。 |
| [12 · 圆顶与圆柱之间的真实台肩](12-dome-step.json) | 主视 | 和 11 对照：这里有台阶，要画实线。 |
| [13 · 跨共面拼板的矩形凹腔](13-pocket-across-join.json) | 俯视 | 保留挖出的矩形边，不能把两块板的拼接处也画成棱。 |
| [14 · 被前挡板遮住半圈的孔口](14-rim-behind-screen.json) | 主视 | 同一个圆，上部可见画实线，下部被挡画虚线。 |
| [15 · 斜通孔的椭圆孔口](15-tilted-through-bore.json) | 俯视、主视 | 近侧椭圆可见，远侧椭圆和被遮挡的孔壁用虚线；实虚线允许在切点相接。 |
| [16 · 两孔之间的窄筋](16-close-parallel-bores.json) | 主视、俯视 | 两个很近的孔仍是两个孔；窄筋两侧的虚线不能合并。 |
| [17 · 带竖孔入口的内腔](17-enclosed-pocket.json) | 主视、俯视 | 上方只露出入口；内腔四边被遮挡，入口孔壁不应延伸到内腔底部。 |
